# 1113_web-

Landing page estatica para ED.SOLUCIONES.

## Objetivo

Presentar la empresa, sus servicios de ingenieria electrica, su oferta de productos electricos y su linea de cortometrajes en un sitio one-page simple y responsive.

## Estado actual

- MVP estatico en HTML y CSS.
- Navegacion por anclas internas.
- Secciones de hero, empresa, servicios, caracteristicas y contacto.
- Sin framework ni proceso de build.

## Estructura

- `index.html`: pagina principal.
- `index.css`: estilos del sitio.

## Uso local

Abra `index.html` directamente en el navegador o levante un servidor estatico simple desde la carpeta del proyecto.

## Siguientes pasos recomendados

- Reemplazar los datos de contacto si aun son provisionales.
- Agregar imagenes reales optimizadas si se quiere reforzar el componente visual.
- Incorporar formulario, portafolio o catalogo en una siguiente fase.
