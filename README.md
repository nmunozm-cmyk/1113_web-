# 1113_web-
## pagina para una empresa de ingenieria electrica
### con esta pagina se busca dar visibilidad a una empresa mostrando los servicios que ofrese, tambien se utilizara para vender productos electricos y cortometrajes, al entrar a la pagina web se encontrara informacion de la empresa, fundadores, imagenes de proyectos realizados etc, habran tres pestañas en las cuales van a estar los servicios que se ofrecen, componentes electricos y cortometrajes.
