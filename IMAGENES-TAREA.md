# Tarea De Imagenes

## Objetivo

Reemplazar los fondos generados por CSS con imagenes reales del negocio y completar el contenido visual del sitio.

## Carpeta sugerida

Crear la carpeta `img/` en la raiz del proyecto y guardar ahi los archivos optimizados.

## Archivos a reunir

- `img/hero-edsoluciones.webp`
  - Foto horizontal amplia de trabajo electrico, equipo o proyecto representativo.
- `img/somos-edsoluciones.webp`
  - Foto del equipo, herramientas o espacio de trabajo.
- `img/servicio-electrico.webp`
  - Imagen de instalacion, mantenimiento o diagnostico.
- `img/productos-electricos.webp`
  - Imagen de componentes, inventario o materiales.
- `img/cortometrajes.webp`
  - Imagen de camara, rodaje, luces o produccion audiovisual.
- `img/contacto-edsoluciones.webp`
  - Imagen sobria para reforzar la seccion de contacto.

## Reglas minimas

- Usar formato `.webp` cuando sea posible.
- Peso recomendado por imagen: menos de `250 KB`.
- Mantener buena iluminacion y encuadres limpios.
- Evitar fotos borrosas, con marcas de agua o capturas de WhatsApp.
- Priorizar imagenes reales del negocio sobre bancos genericos.

## Pendiente tecnico

- Actualizar `index.css` para que cada seccion use las nuevas imagenes.
- Revisar contraste de texto encima de cada fondo.
- Validar carga en movil y escritorio despues del reemplazo.
